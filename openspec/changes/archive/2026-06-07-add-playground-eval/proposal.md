# Proposal: add-playground-eval

## Summary

Add a lightweight playground and evaluation workflow so prompts and outputs can be compared interactively.

## Why

The project should be usable and demonstrable, not only technically correct.

## In scope

- basic playground UI
- side-by-side output comparison
- sample prompts
- benchmark or eval-triggered workflows

## Out of scope

- replacing the backend
- deeply coupled frontend logic
- complex analytics products
